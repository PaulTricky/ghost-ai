## Architecture Decisions

- shadcn/ui uses `@base-ui/react` (not `@radix-ui/*`) — this is the newer underlying primitive library used by the Nova preset.
- Dark-only theme: all color variables set in `:root` directly, no `.dark` class toggle needed. The `@custom-variant dark` directive is kept for shadcn internals.
- Ghost App CSS variables (`--bg-base`, `--text-primary`, etc.) are defined in `:root` and then mapped to shadcn semantic tokens (`--background`, `--foreground`, etc.) and Tailwind utilities (`bg-base`, `text-copy-primary`, `border-surface-border`, etc.) via `@theme inline`.
